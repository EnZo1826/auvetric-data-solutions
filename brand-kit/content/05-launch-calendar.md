## Video scripts

### sensor-to-dashboard · 45–60s

Recording: Screen-record the Architecture Lab on the website (Industrial Intelligence). Label 'Synthetic demo' visible.

1. HOOK (0–3s): 'A pressure reading takes eight steps to become a decision. Each one can break.'
2. Sensor & PLC (3–12s): 'The sensor sends 4–20 milliamps. Below 3.8, the wire's broken, so we flag a fault and never log a fake zero.'
3. Edge & MQTT (12–25s): 'The edge buffers when the network drops, then forwards over MQTT. Duplicates after reconnect get removed on arrival.'
4. API & database (25–38s): 'The API rejects readings with impossible timestamps. Late data lands where it belongs in history.'
5. Dashboard & decision (38–50s): 'The dashboard shows the value and how old it is. A person acknowledges the alarm, and that's logged.'
6. CTA (50–60s): 'Click through it yourself. Link in bio. Auvetric: we connect systems.'

### duplicate-barcodes · 45–60s

Recording: Screen-record the Data Integrity demo stepping from Raw → Profiling → Matching.

1. HOOK (0–3s): 'One product, five barcodes. Which one is right?'
2. Profile (3–15s): 'First, measure. How many barcodes are shared, how many fail the check digit, how many ways is each supplier spelled?'
3. Match (15–30s): 'Same barcode and same supplier code means a duplicate to merge. Same barcode on a different product is a collision. Never auto-merge that.'
4. Validate (30–45s): 'Then the business rules: does case cost ÷ case pack equal the unit cost? Is the margin plausible?'
5. CTA (45–60s): 'Every change gets a reason code. Try it on our site, with synthetic data. Auvetric: we engineer intelligence.'

### margin-report · 30–45s

Recording: Talking head or screen-record of the Reconciliation stage in the demo.

1. HOOK (0–3s): 'Your margin report might be wrong, and it's probably one calculation.'
2. Point (3–20s): 'Supplier case cost ÷ case pack should equal the unit cost in your ERP. If the pack size is wrong in one system, every margin on that product is wrong.'
3. Example (20–35s): 'In our demo, one product's ERP cost is N$19.83 too low. At 310 a week, that overstates margin by about N$6,100 a week. Synthetic numbers, real pattern.'
4. CTA (35–45s): 'Check your top 20 products first. Want help? Link in bio.'

### offline-first · 30–45s

Recording: Phone footage of a gate or field app, or slides using brand cards.

1. HOOK (0–3s): 'If your field app loses data when the signal drops, it was built for the office.'
2. Point (3–25s): 'Offline-first means the device writes locally first, queues every record, and syncs when the network comes back. Each record has an ID, so a retry never creates a duplicate.'
3. Why (25–38s): 'At a gate, the server should never be in the way of the guard.'
4. CTA (38–45s): 'We build these. Auvetric: we connect systems.'
